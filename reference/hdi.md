# Human Development Index (2022)

Human Development Index (2022)

## Usage

``` r
hdi

hdi_scales
```

## Format

A tibble with three columns:

- id:

  the row number

- country:

  191 countries with computed HDI

- hdi:

  the HDI index value

- life_exp:

  life expectancy

- exp_sch:

  expected schooling

- avg_sch:

  average schooling

- gni_pc:

  GNI per capital, logged

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 4
rows and 5 columns.
