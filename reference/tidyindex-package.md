# tidyindex: A Tidy Data Pipeline to Construct, Compare, and Analyse Indexes

Construct and analyse indexes in a pipeline tidy workflow. 'tidyindex'
contains modules for transforming variables, aggregating variables
across time, reducing data dimension through weighting, and fitting
distributions. A manuscript describing the methodology can be found at
<https://github.com/huizezhang-sherry/paper-tidyindex>.
